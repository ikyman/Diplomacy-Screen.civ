# Components of this app:

The user has to Provide:

* A Dialogue Tree.
* The Path Taken in said Dialogue Tree
* The Civilization name, Leader name, and leader title. These technically are part of the dialogue tree, but having them seperate means I can import the "Game.txt" for a default dialogue tree.
* From the above: Pronouns/Genders. 
* Civilization Colour
* Portrait
* "King.avi", or the animated lady in the pink dress with blue stripes.

# Chosen Languages.
The back-end is in GoLang. Hooray! GoLang is very usable.
